# Дизайн-спека: персональный сайт фотографа-документалиста

> Документ адресован AI-агенту, который собирает фронтенд. Это чёрный, тихий, музейный сайт — снимки важнее интерфейса. Не смягчай контраст до "уютного тёмного режима", не добавляй декоративных элементов сверх перечисленных.

---

## 1. Смысловой контур (зачем это так выглядит)

Референс — **Хироси Сугимото** (Hiroshi Sugimoto): «Seascapes», «Theaters», архитектурная серия. Это не про копирование его кадров, а про **логику показа**: как галерея показывает фотографию, когда фотография — единственное, что имеет значение.

Важно понимать разницу с предыдущей итерацией этого шаблона (мингэй / моно-но-аваре, асимметрия, тёплая бумага) — она здесь **не действует**. Новый полюс:

| | Мингэй / моно-но-аваре (было) | Сугимото / галерейная тишина (стало) |
|---|---|---|
| Фон | тёплая небелёная бумага | чёрный, почти беспримесный |
| Композиция | асимметричная (不均斉) | **точная симметрия и выравнивание** — у Сугимото горизонт всегда ровно по центру кадра; сайт должен так же центрировать, а не «оживлять» композицию асимметрией |
| Пустота | ма — пауза, тёплая, человеческая | пустота как **пространство галереи**: строгая, измеряемая, ничего случайного |
| Материал/фактура | бумага, неровный край | ровная плоскость, отсутствие текстуры — снимок не должен «спорить» с фоном |
| Эмоция | лёгкая печаль, рука мастера | созерцательная дистанция, время выдержки — тишина наблюдателя, а не автора |

Практический вывод для агента: **центрируй, выравнивай по строгой сетке, ничего не «оживляй» лишней асимметрией**. Единственный элемент, который может дышать неровно — сам кадр (соотношение сторон снимка сохраняется как есть, не обрезается под сетку).

## 2. Референсы (реальные проекты/подачи)

Ничего не копировать 1:1 — ориентир по духу и по технике:

- **sugimotohiroshi.com** и подача его работ в **Pace Gallery** / **Fraenkel Gallery** — чёрный или почти чёрный фон, один снимок на экран, подпись — короткая строка мелким трекированным капсом (название, место, год), без рамок и виньеток.
- Каталоги **MoMA / Fondation Cartier** для его выставок — типографика: нейтральный гротеск для служебного текста (подписи, номера), сдержанная антиква только для протяжённых текстов (статьи, эссе о серии).
- **Robert Adams / Stephen Shore online portfolios** — как пример сдержанной документальной подачи без графических излишеств: список серий как список, не как плитка с эффектами.
- Анти-референс: Instagram-подача фотографии (карусели, лайки, круглые аватары, теплые тени под карточками) — то, чего здесь категорически быть не должно.

## 3. Палитра — почти беспримесный чёрный

Не тёмно-синий, не тёплый уголь — **нейтральный, близкий к истинному чёрный**, как стена галереи. Текст — не чистый белый (режет глаз на большом чёрном поле), а слегка притушенный, как серебро на фотобумаге.

```css
:root {
  /* база */
  --color-void:       #050505;   /* основной фон — почти чистый чёрный */
  --color-void-raised:#0f0f0f;   /* слегка приподнятая плоскость: карточки серий, подложки под текст */
  --color-silver:      #ededea;  /* основной текст — тёплое серебро, не #fff */
  --color-silver-dim:  #8a8a86;  /* второстепенный текст: подписи, метаданные, даты */
  --color-line:        #2a2a28;  /* тонкие разделители, рамки-волосяные линии */

  /* единственный акцент — использовать почти нигде */
  --color-accent:      #b8860b;  /* приглушённая латунь/бронза — только для активного состояния ссылки или курсора в списке серий, не для декора */

  /* состояния */
  --color-visited:     #57574f;
  --color-focus-ring:  #ededea;
}
```

Правило для агента: **на экране не больше одного акцентного цвета**, и в большинстве экранов — вообще без акцента (только void + silver + line). Если сомневаешься, убери акцент — тишина важнее выразительности.

### 3.1 Исключение: бумажная подача для «книжных» серий

Титульная страница (список серий) **всегда** на `--color-void` — это не меняется. Но если серия — цифровая реконструкция конкретного печатного объекта (фотокниги на тонкой бумаге/кальке, с текстовым «листом», лежащим поверх фотографии), её **страница-просмотрщик** может отказаться от `--color-void` в пользу тёплого бумажного тона — потому что здесь задача не «галерейная тишина», а точность копии физического объекта. Приоритет: верность материалу конкретной книги важнее общего правила черного фона.

```css
:root {
  --color-paper:         #ede4da;  /* тёплая слоновая кость — тон бумаги Hahnemühle, не белый и не чёрный */
  --color-paper-ink:      #2a2a28; /* текст на бумаге — тот же тёмный тон, что --color-line */
  --color-paper-ink-dim:  #8c8577; /* второстепенный текст на бумаге (статус, копирайт) */
}
```

Область действия — только `body` конкретной страницы-просмотрщика (например через класс вроде `.viewer-page`), не весь сайт и не титульная страница. «Калька»/vellum-плашка поверх фото должна быть **того же тона**, что и бумага страницы (см. §6) — так лист кажется одним материалом, а не отдельной вставкой.

## 4. Типографика

- Служебный текст (подписи к снимкам, номера, даты, названия серий в списке, UI): **нейтральный гротеск с широким трекингом**, капс или small-caps — что-то в духе **Neue Haas Grotesk, Suisse Int'l, Inter** (для кириллицы — проверить полноту начертания; резервный вариант — системный `-apple-system`/`Segoe UI`, но не Arial).
- Протяжённый текст (авторский стейтмент к серии, эссе, био): сдержанная антиква **без каллиграфических отсылок** — например **PT Serif, Source Serif, Noto Serif**. Никакого Cormorant/декоративных засечек — это была бы эстетика прошлой итерации (мингэй), здесь она чужеродна.
- Заголовки серий — тот же гротеск, что и подписи, просто крупнее и с тем же трекингом. **Не создавай отдельный "красивый" шрифт для заголовков** — Сугимото-подача обходится одним-двумя начертаниями на весь сайт.
- Подписи под снимком строятся как музейная этикетка: `НАЗВАНИЕ, МЕСТО, ГОД` — заглавными, мелким кеглем, трекинг ~0.08–0.12em.
- Ширина текстового блока для стейтментов — **50–70 символов в строке**, не на всю ширину экрана.

```css
:root {
  --font-caption: "Inter", "Suisse Int'l", -apple-system, "Segoe UI", sans-serif;
  --font-body:    "PT Serif", "Source Serif", Georgia, serif;

  --tracking-caption: 0.1em;
  --measure: 64ch;
  --leading-body: 1.6;
}
```

## 5. Навигация — титульная страница и просмотрщик

Принцип: **два уровня, ничего сверх, и никакого меню вообще.**

1. **Титульная страница = список серий/проектов.** Это не "домашняя страница со ссылкой на список" — список серий *и есть* весь стартовый экран. Никакого отдельного заголовка сайта, никакого хедера, никакого меню, никакой вводной строки над списком. Список **центрирован по экрану** (по вертикали и горизонтали как блок), а не прижат к верху страницы. **Список чисто текстовый — никаких обложек/превью-фотографий на титульной странице.** Каждый пункт: название серии и год, больше ничего. Это не витрина с картинками, это оглавление. Наведение — минимальное (лёгкое изменение прозрачности/цвета текста, не более).
2. **Копирайт — единственный постоянный элемент, и он внизу.** Мелкая строка в самом низу viewport (`position: fixed`/`sticky` у нижнего края или просто в конце документа, если список не скроллится) — текст копирайта (например «© Anton Eremin»), тем же тихим гротеском что и подписи, `--color-silver-dim`, без ссылок и декора. Это единственная "рамка" сайта — сверху ничего нет.
3. **Уровень 2 — просмотр серии.** Открывается по клику на пункт списка. Один снимок на экран, отцентрированный, с местом вокруг (снимок не должен упираться в края viewport). Подпись — под снимком или сбоку, всегда одинаковое положение внутри серии. Копирайт-строка внизу остаётся на месте и здесь.
4. **Переход между снимками** — на устройствах с точным указателем (мышь/трекпад — `@media (hover: hover) and (pointer: fine)`) показываются тонкие глиф-стрелки `‹`/`›`, зафиксированные у левого/правого края экрана: без фона, без рамки, без тени, приглушённого цвета, ярче только на hover/focus. На тач-устройствах эти стрелки **скрыты** — там навигация свайпом (влево — вперёд, вправо — назад), поэтому не нужно рисовать видимые кнопки на мобильном. Клик по самому кадру тоже двигает вперёд. Стрелки клавиатуры `←`/`→` работают всегда, независимо от типа устройства.
5. **Индекс/счётчик** — если нужен, то как `03 / 24`, тем же гротеском, мелко, в углу — не progress bar.
6. **Стейтмент серии** — короткий текст об идее серии, доступен через тихую текстовую ссылку («о серии»), не модальное окно с крестиком, а либо отдельный экран, либо разворачивающаяся панель без анимации-скачка.
7. **Возврат к титульной странице** — тонкий крестик `×` в углу (не круглая кнопка, без фона/тени), присутствует постоянно на странице-просмотрщике **на всех устройствах** — это единственный persistent-элемент навигации помимо стрелок, и он умышленно отходит от более раннего правила «не изобретай постоянный header» — крестик нужен и на мобильном, где нет иного способа выйти к списку. **Проход дальше последнего снимка серии** (клик/свайп/`→` на последнем кадре) — не тупик и не зацикливание, а автоматический переход на титульную страницу.

Псевдо-разметка для агента:

```html
<!-- титульная страница — чисто текстовый список, без изображений -->
<body class="landing">
  <main class="series-index">
    <a class="series-index__item" href="/series/slug">
      <span class="series-index__title">НАЗВАНИЕ СЕРИИ</span>
      <span class="series-index__year">2019</span>
    </a>
  </main>
  <footer class="site-footer">© Anton Eremin</footer>
</body>

<!-- просмотрщик серии -->
<body class="viewer-page">
  <main class="viewer">
    <figure class="viewer__frame">
      <img src="photo.jpg" alt="описание для доступности">
      <figcaption class="viewer__caption">НАЗВАНИЕ, МЕСТО, ГОД</figcaption>
    </figure>
    <nav class="viewer__index">03 / 24</nav>
  </main>
  <footer class="site-footer">© Anton Eremin</footer>
</body>
```

```css
.series-index {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
}
.site-footer {
  position: fixed;
  left: 0;
  right: 0;
  bottom: 0;
  text-align: center;
  padding: 1rem 0;
  font: var(--font-caption);
  letter-spacing: var(--tracking-caption);
  color: var(--color-silver-dim);
}
```

## 6. Взаимодействие и движение

- Переход между снимками — **кросс-фейд по opacity**, без сдвига/параллакса/масштабирования. Это отсылка к длинной выдержке Сугимото: изображение не «влетает», оно проявляется.
- Длительность перехода — **600–900ms**, дольше, чем в обычном UI. Здесь торопливость разрушает смысл.
- Никаких bounce/spring-эффектов, никакого параллакса при скролле. На пунктах титульного списка (текст, без картинок) — только едва заметное изменение прозрачности/цвета при hover/focus, никакого увеличения/подчёркивания-анимации.
- Загрузка изображения — плейсхолдер тоже чёрный (не серый скелетон-градиент), снимок проявляется фейдом, а не появляется скачком.
- Звуков интерфейса нет.

```css
.viewer__frame img {
  opacity: 0;
  animation: surface 700ms ease-in-out forwards;
}
@keyframes surface {
  from { opacity: 0; }
  to   { opacity: 1; }
}
.series-index__item:hover img {
  filter: brightness(1.08);
  transition: filter 400ms ease;
}
```

### 6.1 «Книжный» режим — калька поверх фото

Для серий, скопированных с печатной книги на кальке/тонкой бумаге (см. §3.1): клик по фотографии — это симуляция переворота книжной страницы, не просто next/prev.

- Каждая пара «текст + фото» показывается как **два состояния**, а не одно: сначала полупрозрачная калька с текстом лежит поверх снимка (снимок виден сквозь неё, приглушённый), клик — калька уходит, снимок остаётся один, в полную силу. Следующий клик уже переключает на следующую пару.
- Плашка кальки **того же тона**, что `--color-paper` этой страницы, но с alpha в районе **0.25–0.35** — текст должен быть читаем, но фотография под ним обязана свободно «прочитываться» (пользователь явно просил: калька должна ощущаться прозрачной, а не как отдельный непрозрачный лист).
- Текст на кальке — мелкий и тихий (в районе 0.65–0.8rem), тем же `--font-body`, тёмным `--color-paper-ink`. Это цитата/подпись автора, не UI — не должен визуально спорить с фотографией.
- Не у каждой фотографии есть текст — если по исходной книге на развороте текста не было (например последний разворот), не выдумывай текст, показывай фото как есть, без кальки.
- Плашка позиционируется строго по границам самого кадра (не во весь экран) — прозрачное дыхание вокруг снимка остаётся страницей, а не частью эффекта.

```css
.viewer__vellum {
  position: absolute;
  inset: 0;
  background: var(--color-vellum); /* тот же RGB, что --color-paper, alpha ~0.3 */
  opacity: 0;
  transition: opacity 700ms ease-in-out;
}
.viewer__vellum.is-visible { opacity: 1; }
```

## 7. Чек-лист для агента перед сдачей

- [ ] Фон — нейтральный почти-чёрный (`--color-void`), не тёмно-синий/тёплый уголь (титульная страница — всегда; страница-просмотрщик «книжной» серии по §3.1 — законное исключение на `--color-paper`, это не баг)
- [ ] Если серия в «книжном» режиме: калька того же тона, что бумага страницы, alpha ~0.25–0.35 (фото должно свободно читаться сквозь неё), текст на кальке мелкий и тихий
- [ ] Текст не чистый белый (`#fff`) — используется `--color-silver`
- [ ] Композиция симметрична и выровнена по сетке — никакой нарочитой асимметрии
- [ ] Не больше одного акцентного цвета на экран, в большинстве экранов — акцента нет вовсе
- [ ] Служебный текст (подписи, даты) — гротеск с трекингом, не антиква
- [ ] Протяжённый текст (стейтмент) — сдержанная антиква, не каллиграфический/декоративный шрифт
- [ ] Снимки не обрезаны под сетку — исходное соотношение сторон сохранено
- [ ] Титульная страница — это сам центрированный список серий, без хедера/меню/вводного текста над ним
- [ ] На титульной странице нет ни одной картинки/обложки — только название и год каждой серии
- [ ] На титульной странице единственный постоянный элемент — копирайт внизу, ничего вверху. На странице-просмотрщике постоянные элементы — копирайт внизу, тонкий крестик `×` в углу (всегда) и стрелки `‹`/`›` (только при `hover: hover` и `pointer: fine`) — не больше этого
- [ ] Переходы между снимками — только opacity-кросс-фейд, 600–900ms
- [ ] Нет progress bar, нет карточек с тенями/скруглениями/декором; крестик и стрелки — плоский текст-глиф, без фона/рамки/тени/кружка
- [ ] Проход дальше последнего снимка серии уводит на титульную страницу, а не зацикливается и не застревает
- [ ] Постоянного меню (заголовок сайта, логотип, список ссылок) поверх контента нет
- [ ] Контраст текста к фону проверен (WCAG AA, ≥4.5:1) несмотря на то что оба тона приглушены
- [ ] Кириллица в выбранных шрифтах отображается полно (нет фолбэка на дефолтный sans)
